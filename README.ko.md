# Light Labyrinth

<p align="right"><a href="./README.md">English</a> | <strong>한국어</strong></p>

Light Labyrinth는 닫힌 3D 공간에서 레이저를 목표 지점까지 유도하는 브라우저 기반 퍼즐 게임입니다. 플레이어는 광학 오브젝트를 배치하고 회전하여 빛을 반사하거나 분산시키고, 장애물을 피해 센서에 필요한 빛을 전달해야 합니다.

이 게임은 **연세대학교 2025-2 컴퓨터그래픽스 과목**에서 진행한 프로젝트입니다.

## 게임 진행 방식

각 스테이지는 서로 다른 빛 조작 퍼즐을 제공합니다. 스테이지를 선택하고 주어진 오브젝트를 배치한 다음, 레이저 광원을 클릭해 경로를 시험합니다. 빛이 센서에 정상적으로 도달하면 다음 스테이지로 진행하며, 실패한 시도에는 생명 하나가 차감됩니다.

총 여섯 개의 스테이지에서 다음 내용을 단계적으로 다룹니다.

- 직선 레이저 경로 연결
- 삼각형 및 사다리꼴 거울을 활용한 반사
- 분산 큐브를 이용한 빛의 분리와 재결합
- 고정 장애물을 우회하는 다중 반사 경로
- 이동식 및 고정식 광학 오브젝트를 조합한 퍼즐

## 주요 기능

- 최대 20회 반사를 계산하는 실시간 레이저 레이 캐스팅
- 빛의 반사와 차단, 빨간색·파란색 광선 분산
- 격자 단위 오브젝트 배치 및 축 기준 90° 회전
- 스테이지별 오브젝트 수 제한이 적용된 여섯 개의 스테이지
- 원근, 상단, 정면, 측면, 1인칭 카메라 모드
- 블룸 후처리, 텍스처 재질, 그림자 및 스테이지 클리어 효과
- 생명과 레이저 상태를 보여주는 반응형 전체 화면 인터페이스

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 드래그 | 선택한 광학 오브젝트 이동 또는 카메라 회전 |
| 회전축 위에서 마우스 휠 | 선택한 오브젝트를 90° 회전 |
| 레이저 광원 클릭 | 레이저를 켜거나 끄고 해답 확인 |
| `1` / `2` / `3` / `4` | 원근 / 상단 / 정면 / 측면 시점 |
| `V` | 1인칭 시점 전환 |
| `W` `A` `S` `D` | 1인칭 시점에서 이동 |
| `R` | 현재 스테이지의 이동식 오브젝트 초기화 |
| `Esc` | 1인칭 시점 종료 |

## 기술 스택

- JavaScript ES 모듈
- [Three.js 0.160.0](https://threejs.org/)
- Three.js OrbitControls 및 PointerLockControls
- EffectComposer 및 UnrealBloomPass
- HTML5 및 CSS3

별도의 빌드 과정이나 패키지 설치가 필요하지 않습니다.

## 로컬 실행

JavaScript 모듈과 텍스처 에셋을 불러오므로 `index.html`을 직접 여는 대신 로컬 웹 서버를 실행하세요.

```bash
python3 -m http.server 8000
```

그런 다음 최신 데스크톱 브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다.

## 프로젝트 구조

```text
.
├── index.html              # 게임 UI 및 Three.js import map
├── style.css               # 레이아웃, HUD 및 스테이지 선택 화면 스타일
└── src
    ├── main.js             # 장면 설정, 게임 상태, 조작 및 스테이지 진행
    ├── laser.js            # 레이 캐스팅, 반사 및 분산 로직
    ├── objects.js          # 방, 플레이어, 센서, 거울 및 프리즘 지오메트리
    ├── stages.js           # 스테이지 정의 및 오브젝트 수 제한
    └── assets/textures     # 표면 및 재질 텍스처
```

## 동작 원리

레이저 시스템은 광원에서 가장 가까운 상호작용 가능 오브젝트를 향해 광선을 투사합니다. 반사면에서는 표면 법선을 기준으로 새로운 진행 방향을 계산하고, 분산 큐브에서는 흰색 광선을 빨간색과 파란색 광선으로 분기합니다. 센서가 흰색 광선을 받거나 두 색상의 광선을 모두 받으면 스테이지가 완료됩니다. 재사용 가능한 광선 메시를 이용해 플레이어가 실시간으로 경로를 편집하는 동안에도 효율적으로 시각화합니다.
